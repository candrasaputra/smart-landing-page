Kebijakan Privasi

Terakhir diperbarui: 16 November 2026

Kebijakan Privasi ini menjelaskan bagaimana aplikasi SMART ("Aplikasi"), yang dikembangkan dan dikelola oleh Balai Penyelidikan dan Pengembangan Teknologi Kebencanaan Geologi (BPPTKG), Badan Geologi, Kementerian Energi dan Sumber Daya Mineral Republik Indonesia ("kami"), mengumpulkan, menggunakan, menyimpan, dan melindungi informasi Anda.

Dengan memasang dan menggunakan Aplikasi, Anda menyetujui praktik yang dijelaskan dalam Kebijakan Privasi ini. Kebijakan ini disusun dengan memperhatikan Undang-Undang Nomor 27 Tahun 2022 tentang Pelindungan Data Pribadi.

1. Informasi yang Kami Kumpulkan

a. Informasi akun

Untuk menggunakan Aplikasi, Anda perlu mendaftar dan masuk menggunakan nama pengguna dan kata sandi. Kata sandi dikirim ke server kami melalui koneksi terenkripsi (HTTPS) dan tidak disimpan dalam bentuk teks biasa. Setelah masuk, Aplikasi menyimpan token sesi di penyimpanan aman perangkat (Android Keystore / iOS Keychain) agar Anda tidak perlu masuk berulang kali.

b. Token notifikasi

Aplikasi menggunakan Firebase Cloud Messaging (FCM) dari Google untuk menerima peringatan. FCM membuat token pengenal perangkat dan mendaftarkan perangkat Anda ke topik peringatan (misalnya Awan Panas Guguran, Lahar, dan Curah Hujan). Token ini dikelola oleh Google dan tidak dikirim ke server kami.

c. Pengaturan lokal

Aplikasi menyimpan beberapa preferensi dan status teknis (misalnya status pengaturan izin alarm) hanya di perangkat Anda. Data ini tidak dikirim ke server kami.

d. Data teknis server

Seperti layanan daring pada umumnya, server kami dapat mencatat informasi teknis saat Aplikasi meminta data, seperti alamat IP, waktu permintaan, dan alamat endpoint yang diakses. Catatan ini digunakan untuk keamanan, pemecahan masalah, dan menjaga ketersediaan layanan.

2. Informasi yang Tidak Kami Kumpulkan

Aplikasi tidak:

  • meminta izin atau mengumpulkan data lokasi Anda;
  • mengakses kontak, foto, kamera, mikrofon, atau file di perangkat Anda;
  • menampilkan iklan atau menggunakan SDK periklanan;
  • melacak aktivitas Anda di aplikasi atau situs web lain;
  • menjual, menyewakan, atau memperdagangkan data pribadi Anda kepada pihak mana pun.

3. Izin Perangkat yang Digunakan

Izin berikut diperlukan agar alarm peringatan dapat berbunyi dengan andal:

IzinKegunaan
InternetMenerima peringatan dan memuat data pemantauan Gunung Merapi.
NotifikasiMenampilkan peringatan dan informasi curah hujan.
Alarm & pengingat tepat waktuMembunyikan alarm segera saat peringatan diterima.
Notifikasi layar penuhMenampilkan layar alarm saat ponsel terkunci.
Getar & menjaga perangkat tetap aktifMenggetarkan ponsel dan membangunkan layar saat alarm berbunyi.
Akses mode Jangan GangguMemastikan alarm darurat tetap terdengar.
Layanan latar depan (pemutaran media)Memutar suara alarm hingga Anda menghentikannya.
Abaikan optimasi bateraiMencegah sistem menunda atau memblokir alarm.
Berjalan saat perangkat dinyalakanMemulihkan pengaturan alarm setelah ponsel dinyalakan ulang.

Anda dapat mencabut izin tersebut kapan saja melalui pengaturan perangkat, namun hal ini dapat menyebabkan alarm tidak berbunyi.

4. Bagaimana Kami Menggunakan Informasi

Informasi yang dikumpulkan hanya digunakan untuk:

  • mengirimkan alarm dan notifikasi peringatan dini aktivitas Gunung Merapi;
  • mengautentikasi akun dan menentukan hak akses (misalnya akses petugas untuk mengirim peringatan);
  • menampilkan data pemantauan seperti amplitudo seismik, kegempaan, curah hujan, dan status gunung;
  • menjaga keamanan, mencegah penyalahgunaan, dan memperbaiki gangguan layanan.

5. Layanan Pihak Ketiga

Aplikasi menggunakan layanan pihak ketiga berikut, yang memiliki kebijakan privasinya sendiri:

  • Firebase Cloud Messaging (Google LLC) — untuk pengiriman notifikasi. Lihat Privasi dan Keamanan Firebase serta Kebijakan Privasi Google.

Kami tidak membagikan data pribadi Anda kepada pihak lain, kecuali jika diwajibkan oleh peraturan perundang-undangan atau permintaan resmi aparat penegak hukum.

6. Penyimpanan dan Keamanan Data

  • Seluruh komunikasi antara Aplikasi dan server kami menggunakan HTTPS.
  • Token sesi disimpan di penyimpanan terenkripsi milik sistem operasi perangkat.
  • Kata sandi disimpan di server dalam bentuk hash, bukan teks biasa.
  • Akses ke server dan basis data dibatasi hanya untuk personel yang berwenang.

Meskipun kami menerapkan langkah pengamanan yang wajar, tidak ada metode transmisi atau penyimpanan elektronik yang sepenuhnya aman.

7. Retensi dan Penghapusan Data

Data akun disimpan selama akun Anda aktif. Anda dapat keluar dari akun kapan saja melalui menu Aplikasi, yang akan menghapus token sesi dari perangkat. Untuk menghapus akun beserta datanya secara permanen, silakan hubungi kami melalui kontak di bawah. Permintaan akan diproses dalam waktu paling lama 14 hari kerja. Menghapus Aplikasi dari perangkat akan menghapus seluruh data yang tersimpan secara lokal.

8. Hak Anda

Sesuai peraturan pelindungan data pribadi yang berlaku, Anda berhak untuk:

  • mendapatkan informasi tentang pemrosesan data pribadi Anda;
  • mengakses dan memperoleh salinan data pribadi Anda;
  • memperbarui atau memperbaiki data pribadi yang tidak akurat;
  • meminta penghapusan data pribadi Anda;
  • menarik persetujuan atas pemrosesan data pribadi Anda.

9. Privasi Anak

Aplikasi ditujukan untuk masyarakat umum dan tidak secara khusus ditujukan bagi anak di bawah usia 13 tahun. Kami tidak dengan sengaja mengumpulkan data pribadi anak. Jika Anda mengetahui bahwa seorang anak telah memberikan data pribadi kepada kami, silakan hubungi kami agar data tersebut dapat dihapus.

10. Batasan Layanan Peringatan

SMART adalah alat bantu peringatan dini. Pengiriman peringatan bergantung pada koneksi internet, layanan pihak ketiga, dan pengaturan perangkat Anda, sehingga dapat tertunda atau tidak terkirim. Selalu ikuti arahan resmi dari BPPTKG, BPBD, dan pihak berwenang setempat.

11. Perubahan Kebijakan Privasi

Kami dapat memperbarui Kebijakan Privasi ini dari waktu ke waktu. Perubahan akan dipublikasikan di halaman ini dengan tanggal pembaruan yang baru. Kami menyarankan Anda meninjau halaman ini secara berkala.
